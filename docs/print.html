CASE 1: THE CODE LEAK

Defendant: Rahul Mehta, Software Developer

Rahul pasted proprietary company code into ChatGPT to fix a bug. The code contained a client's database login credentials. Security flagged the breach.

Rahul says: "I was just trying to fix a bug. I didn't notice the credentials. Everyone uses AI to code faster."

CASE 2: THE VOICE CLONE

Defendant: Deepak Sharma, YouTube Creator

Deepak used AI to clone late singer S.P. Balasubrahmanyam's voice and released 5 "new songs" on YouTube. Earned ₹2 lakh. Never disclosed the voice was AI-generated. Fans believed they were real.

Deepak says: "I'm honouring his legacy. The songs are my original compositions — only the voice is AI."

CASE 3: THE ART HEIST

Defendant: BrightAds Pvt Ltd, Advertising Agency

BrightAds typed: "Generate art in the style of Neha Kulkarni's Instagram illustrations." Output looked identical. They won a ₹15 lakh contract. Neha was never contacted, credited, or paid.

BrightAds says: "You can't copyright a style. AI created something new. We saved the client money."
